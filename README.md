# رصد گر ژیان — نسخه ۱.۲

## قابلیت‌ها
- دریافت آب‌وهوا و کیفیت هوا از Open-Meteo.
- دریافت خودکار دلار آزاد، طلای ۱۸ عیار، ربع سکه، نیم سکه و سکه امامی از API عمومی Iran Market Data.
- تلاش برای دریافت نمادهای نفت برنت و WTI در صورت انتشار در فهرست منبع؛ در غیر این صورت فیلد نفت برای ورود دستی باقی می‌ماند.
- تبدیل نرخ‌های تومانی به ریال در صورت اعلام واحد `IRT` توسط API.
- ثبت دارایی‌ها، تاریخچه، نمودار، خروجی Excel و پشتیبان JSON.
- بازیابی فایل پشتیبان JSON با انتخاب فایل از گوشی.
- ذخیره‌سازی محلی روی دستگاه.

## منبع قیمت و محدودیت
منبع قیمت: `https://iran-market.github.io/` و فایل JSON:
`https://raw.githubusercontent.com/iran-market/iran-market.github.io/main/data/latest.json`

مستندات منبع اعلام می‌کند داده‌ها بدون کلید API و تقریباً هر ۳۰ دقیقه منتشر می‌شوند. این سرویس تضمین دسترس‌پذیری یا صحت معاملاتی نمی‌دهد. برنامه واحد ارز را از فیلد `currency` می‌خواند و فقط قیمت‌هایی را به‌روزرسانی می‌کند که نماد و واحدشان قابل تشخیص باشد. اگر نفت در پاسخ موجود نباشد، قیمت آن خودکار تغییر نمی‌کند. قیمت‌های بازار برای تصمیم خریدوفروش کافی نیستند و باید مستقل بررسی شوند.

## ساخت APK با EAS
پروژه برای تولید APK با پروفایل `preview` تنظیم شده است. ساخت فایل APK واقعی نیازمند حساب Expo و اجرای build ابری است؛ این ZIP به‌تنهایی APK نیست.

1. فایل ZIP را روی رایانه باز کنید.
2. Node.js نسخه LTS را نصب کنید.
3. در پوشه پروژه اجرا کنید:
   ```bash
   npm install
   npx eas-cli login
   npx eas-cli build:configure
   npx eas-cli build -p android --profile preview
   ```
4. پس از پایان ساخت، لینک APK در خروجی EAS نمایش داده می‌شود؛ آن را در گوشی اندروید باز و نصب کنید.

برای ساخت از گوشی اندروید به‌تنهایی، محیط خط فرمان و حساب Expo لازم است؛ ساخت مستقیم APK در این محیط گفتگو انجام نشده است.
