# مدیریت کالا — نسخه اولیه اندروید

این پروژه یک MVP آزمایشی با Expo و SQLite محلی است.

## امکانات
- رابط فارسی و راست‌چین
- داشبورد موجودی و هشدار کمبود
- ثبت کالا با بارکد، موجودی اولیه و قیمت خرید/فروش
- جست‌وجوی کالا بر اساس نام یا بارکد
- ثبت عملیات ورود و خروج با کنترل موجودی منفی
- گزارش‌های پایه موجودی
- ذخیره‌سازی محلی SQLite و کارکرد بدون اینترنت
- پوسته روشن/تیره

## ساخت APK با GitHub Actions
از بخش Actions در مخزن، گردش‌کار **Build Modiriat Kala Android APK** را انتخاب و گزینه **Run workflow** را اجرا کنید. فایل APK پس از موفقیت در بخش Artifacts همان اجرا قابل دریافت است.

## محدودیت‌های این MVP
همگام‌سازی ابری، حساب کاربری و چندفروشگاهی واقعی، نقش‌ها و مجوزها، اسکن دوربین بارکد، چاپگر، اکسل، خریدوفروش و فاکتور کامل، حسابداری، GPS و ناوگان هنوز پیاده‌سازی نشده‌اند.
